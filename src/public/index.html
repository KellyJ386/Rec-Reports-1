Daily report workflow

Report templates and submissions

This first production slice models configurable report templates, required answers, immutable submitted snapshots, attachments, audit events, and outbox notifications. Expand a submission's "Attachments" toggle to upload evidence (draft submissions only) or download anything already on file.

Manager review

Report review inbox

Filter submissions by status, date range, department, and template. Opening a submission renders its answers from the exact schema version it was filled against (never the current template, even if it's since been re-published), plus its attachments, any validation warnings it was submitted with, and a PDF export.

Scheduling workflow

Weekly schedule board

Pick a week to see its shifts grouped by day, assign or unassign staff on a shift card, generate shifts from templates, and validate or publish once coverage is ready. Conflict and certification badges call out anything blocking publish.

Incident workflow

Incident reports

Report a new incident, then track it from draft through submission: follow-up actions, escalation acknowledgement/resolution, an immutable amendment history, and evidence attachments. High/critical severity requires an immediate-actions note before a report can be created.

Maintenance workflow

Work orders

Filter by open/mine/overdue/priority, create a work order, and open one to see its comment thread and change its status or assignee. Expand a work order's "Attachments" toggle to upload a photo or document, or download evidence already on file.

Communications workflow

Messages

Publishers can compose a message with a channel, priority, audience, and optional required acknowledgement. Opening this panel marks each visible message delivered and read; required-acknowledgement messages show their acknowledgement state.

Training workflow

Training assignments

Training connects courses, modules, assignments, progress, completions, and certification events back to scheduling and incident follow-up requirements.

Certification wallet

My certifications

Every certification on file for the current facility, with a live status derived from its expiry and renewal window, plus whether evidence has been uploaded.

Admin control center

Facility configuration governance

Admin controls manage module toggles, inherited settings, branding profiles, reviewed change requests, and audit-ready configuration events.
